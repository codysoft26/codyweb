NullClaw Architecture

Explorando Agentes Autónomos y Webhooks en Tiempo Real

🤖 ¿Cómo funcionan los Agentes?

Los agentes de NullClaw combinan modelos de lenguaje avanzados con bucles de razonamiento iterativo y herramientas del sistema operativo.

  • Contexto persistente: Memoria estructurada (SQLite/Híbrida) que evoluciona con cada interacción.
  • Tool Use autónomo: Ejecución controlada de shell, llamadas HTTP, gestión git y utilidades.
  • Personalidad y directrices: Identidades definidas en archivos modulares (SOUL.md, AGENTS.md).

⚡ ¿Cómo funcionan los Webhooks?

El canal Webhook permite conectar servicios externos, pasarelas y aplicaciones de terceros de forma síncrona o asíncrona.

  • Recepción de eventos: Captura peticiones HTTP POST con payloads JSON estructurados.
  • Disparadores automáticos: Activan subtareas, notificaciones (Pushover) o respuestas automatizadas.
  • Integración multicanal: Conecta flujos externos directamente con las sesiones del agente.
